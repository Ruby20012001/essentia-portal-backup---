# Brand assets

- `logo-dark.png` — white essentia wordmark, transparent PNG, for dark
  (espresso) surfaces. Extracted from the board-distributed
  `Essentia_Portal_Complete_Briefing.html` letterhead (byte-identical across
  all three TechPartner documents), corresponding to CLAUDE.md's `ld.b64`.
- `logo-light.png` — MISSING. CLAUDE.md specifies a black transparent PNG
  (`ll.b64`) for light backgrounds. Until the official file is supplied, light
  surfaces derive it from `logo-dark.png` via CSS `filter: brightness(0)`.

Usage rules (CLAUDE.md): the logo is always an image, never text.
